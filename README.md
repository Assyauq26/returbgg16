# Retur BGG 16

Static web app for recording return AWB/resi packages collected by sellers.

## Stack
- Frontend: HTML/CSS/JavaScript, deployable on Netlify
- Backend: Google Apps Script Web App
- Data: Google Spreadsheet

## Pages
1. Input Resi
2. Pencarian Resi/AWB

See `docs/apps-script.gs` and `docs/SETUP.md` for backend and deployment setup.
